# AtomWeft（原子织图）0.3.2

将分子和晶体结构转换为 PowerPoint 可编辑图形。数据在本机处理，不上传结构文件。


## 安装

1. 保存并关闭 PowerPoint。
2. 双击 `AtomWeft-0.3.2-Setup.exe`，等待安装完成。
3. 重新打开 PowerPoint，点击 **AtomWeft → 导入分子结构**。

安装包包含独立的 Python 和全部运行依赖，可离线安装，不要求管理员权限，也不改变系统 Python。默认安装在当前用户的 `%LOCALAPPDATA%\Programs\AtomWeft\0.3.2`。开始菜单也会提供 AtomWeft 入口。

ZIP 版解压后双击 `Install.cmd` 完成同样的安装；仅预览或导出时也可直接运行 `app\launch.cmd`。安装后的文件夹请勿直接移动；需要迁移时在新电脑重新运行安装包。安装器不会关闭或保存用户的文稿。

运行要求：Windows 10/11 x64、桌面版 Microsoft PowerPoint 2016 或更新版本、现代浏览器。已实测 64 位 PowerPoint；功能区组件兼容 32/64 位 Office 注册，但本版本未在 32 位 Office 实机验收。安装程序未做商业代码签名，组织设备可能受软件安装策略限制。

## 基本使用

导入 CIF / mmCIF / MOL / SDF / PDB / XYZ，选择键线式、球棍式或空间填充式。调整元素颜色、半径和观察角度，选择“插入当前幻灯片”或“导出 PPTX”。在 PPT 中取消组合即可编辑原子、键、配位面和标签。

### 景深

- 透视强度：模拟近大远小，不改变结构坐标。
- 离焦淡化与透明度：按可见结构沿视线的深度计算，焦点附近清晰，向焦点前后逐渐增强；不再由横向结构尺寸决定。
- 焦点位置、清晰范围、虚化强度：模拟焦外柔化，也可对焦选中原子。
- 所有效果都能关闭。原子逐个计算焦外虚化；键保持完整，双色键只保留两段元素色，不因景深细分。需要沿键渐变透明时使用完整细长矩形的原生渐变填充。多面体面也使用原生渐变，保留完整可编辑面。虚化强度按各个原子、整段键或整面的深度计算；浏览器使用模糊滤镜，PPT 使用原生柔边，外观略有差异，不是逐像素光学渲染。

### 配位多面体

导入晶体 CIF 后自动识别配位中心并开启 Polyhedra。优先读取 `_geom_bond_*` 键表及对称码；没有相应显式表时，按晶胞、空间群和周期邻居推断最近配位壳层，并在界面提示推断来源。自动中心包括金属及 B、Si、Ge、P、As、S、Se、Te。

也可切换为按中心元素或指定选区，使用现有连接或距离截断，并筛选配体元素。各面根据法线与观察者左上方固定光源计算明暗，旋转结构时实时更新；“面光照强度”控制效果，设为 0 恢复纯色。每个面输出为原生可编辑自由多边形。

多面体是配位原子的三维凸包，至少需要四个非共面邻居。最多显示 200 个中心，每个中心最多 24 个邻居。自动模式会补全边界外的配位顶点，不增加可编辑原子列表。几何推断不是价态或化学配位判定；无序结构和畸变较大的配位壳层仍需核对，必要时使用手动中心与距离设置。旧项目不含自动配位元数据时，需要重新导入 CIF。移动原子保留导入时的配位关系；增删或换元素后可重新导入或切换手动模式。

### 结构编辑与局部风格

- 工具栏切换旋转、选择、框选、移动；Shift 多选。
- 拖动选中原子沿观察平面移动；Alt 拖动沿视线移动。也可输入选区中心的 XYZ 坐标。
- 增加原子、删除原子、替换元素；选择两个原子后新增、删除或改变键级。
- 将选区保存为命名片段，便于再次选取。
- 对选区单独应用表示方式、小球维度、键样式、颜色和倍率，也可隐藏或恢复全局样式。
- 撤销/重做保留最近 30 次结构和样式编辑。移动保持现有键；需要时按当前坐标重建连接。
- 不同局部键风格交界处使用全局键风格；两端均为空间填充时不显示连接。

编辑是几何操作，不执行能量优化或价态校验。按距离重建全部连接会替换原来的显式键级。XYZ 导出仅包含元素和坐标；请用“保存项目”保留编辑后的连接、局部风格、片段、晶胞和视角。项目 v2 可读取旧 v1 项目，旧版软件不能读取 v2。

## 范围与边界

坐标单位 Å。元素大小支持统一、共价半径和范德华半径。XYZ/CIF 及部分 PDB 连接通过距离推断，不代表确定的化学成键。SDF、PDB 和 XYZ 的多分子/多帧输入取首个分子或模型。CIF 使用 Gemmi 展开对称位置，有限超胞之外的连接不显示。

原子上限 4000，连接上限 16000，直接插入上限 8000 个图形，PPTX 导出上限 30000 个图形。输出是固定视角的二维图形，遮挡采用深度排序；互相穿插的球和多面体不能完全复现逐像素三维遮挡。PPT 中单独移动形状不会自动更新分子连接；重新旋转请回到 AtomWeft 项目。

## 修复与卸载

入口缺失时，保存并关闭 PowerPoint，再运行安装目录中的 `repair-startup.cmd`。它备份并清理仅属于 AtomWeft 的旧禁用记录，不更改其他加载项或安全策略。

从开始菜单运行“Uninstall AtomWeft”，或在 Windows 已安装应用中卸载。卸载移除加载项注册和快捷方式，保留安装文件与项目，避免删除用户数据；不再需要时可自行删除安装文件夹。

## 从源码运行与测试

Windows x64，Python 3.13，Node.js 22 或更新版本（仅测试需要）。

```powershell
git clone https://github.com/KHZ-beep/AtomWeft.git
cd AtomWeft
python -m pip install --index-url https://pypi.org/simple --target vendor -r requirements.txt
python server.py
```

浏览器编辑器可预览和导出 PPTX；直接插入需桌面版 PowerPoint。安装功能区入口：先保存并关闭 PowerPoint，再运行 `install-addin.cmd`。构建使用 Windows .NET Framework 自带的 C# 编译器。

运行 `python tests/run_all.py`，按顺序生成测试夹具并运行 Python / JavaScript 测试，无需打开 PowerPoint。测试结果不代表各版本 Office 的实机验收。

安装包构建：见 [distribution/BUILD.md](distribution/BUILD.md)。源码仓库不包含安装 EXE 或依赖二进制。
